## Scope and method

The machine-readable ledger records source SHA-256 hashes, exact anchors, test identifiers and immutable line links. `tools/check_audit.py --source-repo PATH` checks these against the pinned Git object without checking out or modifying the SRT source. It checks evidence references, not behavioral correctness.

The two drafts contain normative-policy proposals and threat-model judgments as well as factual implementation claims. These are not made source-confirmed by this audit. All initial draft sections were screened; complete admission topology/cipher combination handling, source-address ingress filtering, full GCM nonce/AAD processing, key-confirmation semantics, runtime exhaustion teardown and ACP1 topology variants remain targeted follow-up work. The base SRT revision, Control/Sensor and ancillary extensions have not received this depth of audit.

## Priority findings

1. The timestamp delta is emitted as zero and only codec serialization/deserialization references it; do not specify nonzero clock mapping as implemented behavior. Codec fixtures contain nonzero values, demonstrating why a round-trip test alone is insufficient. A proposed zero-only interoperable rule would narrow current decoder acceptance and needs an explicit decision.
2. Repair window depends on the requesting member’s current RTT. It is not frozen in the shared tally; different receiver RTTs can produce different expiry decisions. Specify this precisely or deliberately change the future profile.
3. A four-slot key cache is not a guarantee of four consecutive usable historical generations after skipped idle periods. Define repair eligibility independently of storage capacity.
4. KM replay handling accepts identical request retries and matching-current responses, whereas FEC rejects repeated counters. Avoid a blanket claim that all authenticated traffic is accepted only once.
5. Multicast original-send transient failure and repair-send transient failure have different recovery paths; local queue acceptance must not be confused with successful emission.
